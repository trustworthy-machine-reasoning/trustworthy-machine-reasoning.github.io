# Trustworthy Machine Reasoning Tutorials

Static tutorial websites published through GitHub Pages from the root of `main`.

## Pages

- [ACML 2026](https://trustworthy-machine-reasoning.github.io/acml26-tutorial.html): Trustworthy and Efficient Machine Reasoning with Foundation Models.
- [PAKDD 2026](https://trustworthy-machine-reasoning.github.io/pakdd26-tutorial.html): Trustworthy and Efficient Machine Reasoning with Foundation Models.
- [AAAI 2026](https://trustworthy-machine-reasoning.github.io/aaai26-tutorial.html): Trustworthy Machine Reasoning with Foundation Models.

`index.html` redirects to the latest tutorial. Each tutorial retains its own URL; related-tutorial links connect the pages. Shared styles are in `static/css/`, and presenter portraits are in `img/`.

## Updating ACML 2026

Edit `acml26-tutorial.html` directly. Content follows the ACML 2026 proposal with three presenters and three 50-minute sessions. Public contact: cszkzhou@comp.hkbu.edu.hk.

- Date and format: [official tutorial call](https://www.acml-conf.org/2026/calls/tutorials/), confirmed by the acceptance email.
- Conference venue: [official venue page](https://www.acml-conf.org/2026/venues/venue/).
- As of 30 September 2026, the tutorial start time and room have not been found in the official program or supplied emails; keep them as TBA until confirmed.
- Materials currently say “Coming soon”; replace this status with real resource links when available.

For a local preview, run `python3 -m http.server 8000` in this directory and open `/acml26-tutorial.html`. Check desktop and mobile layouts and local links before publishing.

The layout is adapted from the previous tutorial pages and credits [Nerfies](https://github.com/nerfies/nerfies.github.io).
